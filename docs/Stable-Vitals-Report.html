What is included

Auth Done

Signup, login, current user, and logout. Logout revokes the token.

Password reset Done

Forgot password, verify the 6-digit code, set a new password. Email uses Nodemailer.

Horses Done

List, add, edit, archive, and move to a new stall.

Water sensor API Done

Accept water consumed in liters with a horse ID and return authorized latest readings or history.

Profile Done

Full profile, staff notes, care log, and a 30-day care report, including CSV.

Subscription Done

Current plan, checkout, and payment confirmation webhook.

Team Done

Settings Done

How the app flows

1
Create the barnPOST /api/v1/auth/signup creates the barn, the owner, and a subscription with status none.
2
Sign inPOST /api/v1/auth/login returns a 7-day token. GET /api/v1/me shows the user and role.
3
Add horsesList, add, edit, archive, or move a horse. Moving a horse updates the stall and sensor id.
4
Keep the profileStaff notes, care entries, and a care report for the last 30 days. The report can be JSON or CSV.
5
Handle an alertA person creates the alert, acknowledges it, then resolves it with an action.
6
Invite the teamThe owner invites a member and sets a role.
all_access
Horses, team, billing, and settings.
basic_access
Notes, care, alerts, and settings.
view_only
Only the horses they are allowed to see.
7
Barn settingsUpdate check sensitivity and which notifications are on.
8
Buy a planCheckout stays pending until POST /api/v1/webhooks/payment confirms payment.succeeded.
9
Reset a passwordRequest a code, receive it by email, verify the code, then set a new password. Older tokens stop working.
10
Log outPOST /api/v1/auth/logout revokes the token.
Outside this phase. Automatic alerts from sensor readings are not built yet. Sensor ingestion requires SENSOR_API_KEY in .env. Checkout does not charge a card by itself. The reset email is sent only after SMTP_HOST, SMTP_USER, SMTP_PASS, and SMTP_FROM are set in .env. Until then, development returns the code in the API response.
